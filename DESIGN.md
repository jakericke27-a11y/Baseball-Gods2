# Baseball Gods — Design

Living document. Settled decisions only; open questions are listed at the bottom.
Superseded material lives in git history, not here.

## The game
A GM sim where the Baseball Gods rewrite the rules each year (voted buffs/nerfs), with
arcade-inflated numbers ("the highlights of history"), a satirical tone, clutch moments,
and decision cards that pause the sim at big moments. All play happens in the browser.

## Architecture
- **TypeScript, runs entirely in the browser.** No server, no Python, no API layer.
- `src/engine/` is pure logic: no DOM, no UI imports. It runs in Node (tests, calibration)
  and in a browser Web Worker (the game) with the same code.
- All randomness goes through a seeded `Rng`. Same seed → identical season, byte for byte.
- Saves: the whole league as one .zip (`save.json` + `logs.bin`), the same bytes in IndexedDB (one slot
  today, `slot1`; built for more) and in an exported file. Loading never replays, so saves survive engine
  changes; formats upgrade on load (`engine/snapshot.ts`, `ui/savefile.ts`). Safari can clear site data
  after 7 days without a visit, so file export is not optional, and the game asks for persistent storage.

## At-bat model (pitch by pitch) — `src/engine/atbat/`
Each pitch: location (zone/heart/edge/chase) → swing decision → contact → foul or fair →
if fair: contact quality → launch type (GB/LD/FB/PU) → outcome.
Pitch counts, deep-count battles, first-pitch homers and full-count walks are emergent.

Every probability is `sigmoid(league base + Σ sensitivity × rating shift + situation)`.
A 50-vs-50 matchup sits on the league base; nothing can hit 0% or 100%.

### What each rating does
See CURVES.md (regenerated by `npm run curves`). Headline, baseline environment, everything else 50:
power 30/50/80 → 11 / 18 / 36 HR per 600 PA; contact → 35% / 20% / 11.5% K.
Three-true-outcomes profile (pow 72, con 32, eye 66): ~28% K, ~11% BB, ~25 HR/600.

### League environment (`environment.ts`)
A handful of league-wide dials (log-odds shifts): zone, contact, protect, foul, hr, hit,
xbh, triple, hbp, plus **spread** (star power: scales every rating's effect).
The calibrator sets the dials so a neutral year hits the targets. These dials are the
future sim sliders. Ratings are never touched by the dials.

### Calibration (`tools/calibrate.ts`)
Targets in, dials out, verified on 5 leagues the calibrator never saw. ~15 seconds.
Presets: **`baseline` (default, ~2019 MLB, ~9.9 runs/game)**, `steroid` (~11.4), `slugfest` (~12.2, the April targets).
Runs are a consequence of the batting line (checked with BaseRuns), not a separate target.
Baseline targets: K 20%, BB 8.5%, AVG .252, HR/600 20, 2B/600 28, 3B/600 4.5, HBP 1%, P/PA 3.85, SwStr 9.5%.

### Outliers
The baseline is realistic on purpose. Monster seasons come from stacking layers — ratings,
Gods' favor, the year's decree, traits, streaks, context — each a bounded log-odds shift, so
they multiply odds smoothly and an ultra-rare 100-HR season stays possible without breaking anything.

## Game loop (`src/engine/game/`)
`simulateGame(away, home, params, rng)` plays a full game pitch by pitch: base/out state, baserunning
(runner speed vs fielder arm; sends, first-to-third, tag-ups, throw-outs), double plays, fielder's choices,
sac flies, steals, wild pitches/passed balls, errors (glove), extra innings, walk-offs, a bullpen manager
(CL/SU/MR/LR roles, save situations), W/L/S, box score, and clutch moments.
- **Defense:** each ball in play is sprayed to a fielder (pull/center/oppo by handedness and power); range
  turns hits into outs, hands prevent errors, arms hold runners and cut down infield hits.
- **Clutch:** RISP uses clutch-RISP (1.0×), late & close uses clutch-pressure (0.75×), both = 1.5× the
  average; batter minus pitcher, 0.10 log-odds per SD, applied to contact, quality and chase.
- **Bookkeeping guards (tested):** every run is credited to a runner AND charged to a pitcher; RBI ≤ R;
  ER ≤ R; outs reconcile per side; every game has a W and an L; runs within 4% of BaseRuns.
- **Moments tagged:** grand slam, walk-off (incl. wild pitch), go-ahead homer 7th+, clutch hit (RISP, late &
  close), 10+ pitch at-bat, immaculate inning, cycle, three-homer game, golden sombrero, no-hitter, perfect
  game, complete-game shutout.
- Running-game constants are tuned to 2019: SB 0.42 / CS 0.13 / GIDP 0.71 / SF 0.22 / E 0.63 per team-game.

## Season (`src/engine/season/`)
- **Schedule** (2019 division-heavy): 19 vs each division rival, six 7-game + four 6-game league opponents,
  4 vs each team of one interleague division (pairing rotates by year). Exactly 162 games, 81 home,
  2–4 game series, a league-wide off day every 4th round, All-Star break at the halfway point (~191 days).
- **Rotation (approved):** order is the structure; size locked per team (15% four-man, 70% five, 15% six).
  Fatigue decides skips → next rested man in order → long-man spot start. "Skip the fifth after an off day"
  is a per-team toggle. Short-rest starts only for boosted recovery (`abilities.bounceBack`).
- **Fatigue (0–100):** +25 per appearance + 80 × pitches/budget; −25/day × (1 + bounceBack). Starters go at
  ≤ 20 (four-man rotations at ≤ 30, so they run tired by design); relievers enter at ≤ 20, so typical arms
  can't go back-to-back but high-stamina ones can.
- **Bullpen (your philosophy):** ~3 pitchers per team-game, ~70% of games use 3 or fewer. Starter budget =
  60 + stamina (fade starts at 65% of budget). Relievers get a planned stint from stamina (30 ≈ 1 IP, 45 ≈ 2,
  60 ≈ 3): closer finishes (six-out saves with stamina ≥ 45), setup covers 7th–8th, long men 2–3 IP,
  middle relief soaks blowouts. Early hooks only for runs allowed, pitch count, or the 9th-inning save handoff.
- **Standings:** W-L, GB, RS/RA, home/away, streak, last 10; display ties broken by run differential.
- **Postseason** (`season/postseason.ts`, 2019 format): 3 division winners (seeds 1–3) + 2 wild cards per league;
  one-game wild card, best-of-5 DS (2-2-1; 1 vs the wild card winner, 2 vs 3), best-of-7 LCS and final (2-3-2;
  final home field to the better record). The final is the **Galaxy Series** (working name). Ties for a division or
  the last wild card are played off as Game 163s, which count in regular-season standings and stats (a 3-way tie is
  a ladder over consecutive days); other seeding ties: head-to-head, then run differential. Calendar: an off day
  after the season (none after a Game 163), then rounds on fixed starts with travel days inside series. October
  starters: the best rested of the top four (then the rest), on normal rest (5 days start to start) unless boosted
  recovery. Postseason stats are kept apart. The schedule grows as games are added, so `isOver` means the whole
  year; `regularOver` the regular season. Calibration and stat tools play regular seasons only.

## Years and the offseason (`engine/development.ts`, `engine/offseason.ts`)
- **Hidden development:** each player has a potential per rating, a growth factor (busts < 0.7 < late bloomers
  > 1.3) and an aging factor, all log-normal around 1. Never shown; scouting (4.5) and stats are how you learn them.
- **Curves per rating:** growth closes the gap to potential (about 1 point left at the peak age), then a plateau,
  then a decline that steepens each year. Speed peaks at 24 and fades from 27; discipline and control mature at 29
  and hold to 32–33. Young potentials drift a little until 24, so prospects surprise.
- **The pipeline:** 150 sixteen-year-olds a year across the regions, rolled like league players but as potential.
  Until the draft (1.6) everyone undrafted becomes a free agent at 23. Draftable ages will be 18–22.
- **The winter:** age and develop everyone; retire by age × value (fringe players pushed out, stars hang on);
  free agents 34+ retire and the pool keeps its best 250; every team refills to 22 position players + 18 pitchers,
  worst record first, by position need, then up to two upgrades (+4 value). Pitcher roles follow stamina.
- **Year 1 ages** are shaped like a settled league (mean ~28.5). The pipeline lives on its own random stream, so
  Year 1 rosters and ratings are exactly what they were: no recalibration.
- **No pull back:** the dials carry over unchanged; `npm run years -- 20` shows ages (28–29), talent (mean ±1,
  spread settling from 5.3 to ~4.3 as teams replace Year 1's random scrubs) and the league line (AVG .256–.266,
  ~10 R/G) holding over 20 years.

## Event log (`src/engine/log.ts`)
Per game: PA events (inning/half, outs+bases before, batter, pitcher, play, fielder+batted-ball type,
quality, runs+RBI, every pitch as one byte, runner movements incl. where outs happened), steals,
wild pitches, pitching changes. ~4 MB raw / ~2.5 MB gzipped per season. Play-by-play and box scores
are generated from it (`game/text.ts`). Pitch bytes reserve 3 bits for **pitch type** (planned).

## Carried over from the 2026 Python design (to port next)
- Persistent pitcher fatigue (0–100): accumulation ∝ pitches/budget × 80, recovery 20/day,
  SP start ≤ 40%, RP enter ≤ 40%, ace priority within 10%, over-rested after 2 days at 0%
  (±8%, clutch-biased), rotation size flag 4/5/6. In-game degradation starts at 60% of budget.
- Two-rating clutch (RISP, pressure), pitcher clutch counters batter clutch, archetype badges.
- Display rounding of 20–80 ratings to the nearest 5 (exact values stored).
- Generation: 14 regions, ages, handedness, 40-man rosters (`generate.ts`).

## Pitcher usage (APPROVED 2026-10-03 — next milestone)
Rotation order honoring the 4/5/6 flag is the structure. Fatigue decides skips, spot starts, openers, and
unusually short-rest starts — the latter only for pitchers whose recovery is boosted (innate or Gods-given
"bounce-back" abilities). Those abilities are meant to be among the game-breaking outlier factors.

### Old proposal text
Root cause of the old rotation bug (aces with 47–56 starts): recovery 20/day + "start the ace
whenever he's within 10 of the most rested" puts the ace back at zero after 4 days, tied with
everyone, winning the tie. Proposed port: a real rotation order honoring the 4/5/6 flag; fatigue
decides skips, spot starts and openers; "ace priority" becomes skipping the 5th starter after
off days (a strategy toggle); recovery tuned so a full start takes ~4 days to clear.

## Lessons from the Python engine (April 5 build, re-run 2026-10-03)
- Cascade order inverted extra-base hits: 13 doubles / 5.9 triples per 600 PA (MLB ~27 / ~2.5).
- Scoreboard ran ~15% below what its own batting line implies; RBI total exceeded runs scored.
- Closers averaged a 7.15 ERA; starters averaged 40 starts.
New-engine guards: runs vs BaseRuns check, RBI ≤ R, per-team start limits by rotation size.

## Design philosophy (2026-10-03)
Realistic baseline; the fun is in finding combinations that BREAK it (ratings + abilities + favor +
decree + context), exploiting them while they last, until players age out or the league catches up and
the meta moves on. Broken should feel earned and temporary, not random.

## Music & audio (cue slots — the player composes the soundtrack)
- Files live in `public/music/`, listed in `public/music/manifest.json`:
  `{ "id": "hub", "file": "hub.ogg", "loopStart": 4.2, "loopEnd": 68.0, "volume": 0.8 }`.
  Missing files = silence, never an error. Loops jump from `loopEnd` back to `loopStart` (intro plays once).
- Format: master as WAV; ship OGG Vorbis (plays in all current browsers; Safari since 18.4), optional MP3 twin.
- Browsers block sound until the first click/keypress, so the game opens on a "press any key" title screen.
- Starter cue list: title, hub (regular season), sim-running, pennant race, postseason, offseason/the Gods,
  plus short stingers: decree, walk-off, home run, no-hitter. Final list is the composer's call.

## Clubhouse (2026-10-13) — `src/ui/clubhouse/`
Plain JS + CSS, appended to the page by the build between `<!-- clubhouse:start -->` and `<!-- clubhouse:end -->`.
It finds the game through `window.__bg` (set in `src/ui/main.ts`), wraps `app.render`, mounts into
`.frame.screen-home`, and opens screens through the game's own actions, so it always shows the real league.
If it throws, it turns itself off and the dashboard shows. Art slots, rooms and controls: the project's clubhouse notes.

## First playable build (2026-10-09) — `src/ui/`
- One page, no server: title (press any key; music starts) → pick a team (its colors dress the UI) → home.
- Home (H3 layout): Your Team, division standings, Tonight (probables, bullpen readiness), Wild Card race (scrolls,
  playoff line, your row outlined), Leaders strip, Headlines ticker. Windows open their full screens.
- Footer: icon nav (Home, Standings, Games, Leaders, Roster, Game Log, Settings) + actions. On your game days the
  main action is WATCH; SIM DAY / WEEK / MONTH / TO END otherwise (multi-day sims show progress and can stop).
- Watching (G2 layout) is a faithful replay of the game the engine already played: next pitch / at-bat / inning /
  to end, AUTO, Space = next pitch. Players stand on the pixel field; the light follows the inning.
  Any finished game can be replayed from its box score or the game log.
- Screens: standings (playoff picture, full columns), games (scoreboard by day + box scores), leaders (12 boards),
  roster (any team; ratings to the nearest 5, fatigue bars), game log (your games, play-by-play by half-inning,
  detail setting), news (every headline), player card (ratings, birthplace, season line), settings.
- Streak heat: hot 1/2/3 = W3/W5/W7 or 7/8/9 of last 10; cold 1/2/3 = L4/L5/L7 or 3/2/1 of last 10. Bigger flames and
  icicles at higher levels; two-frame flicker; no motion with reduced-motion settings.
- Saves: the engine is deterministic, so a save is (seed, team, day). Saved to the browser after every sim, plus a
  ten-character password that restores the year on any device (version-stamped; engine changes bump the version).
- The ballpark is an original procedural pixel stadium (camera high behind home, open sky above): day/dusk/night
  palettes, a temple on the mountain, light towers, scoreboard, crowd. Your photo was reference only.
- Headlines: grand slams, walk-offs, late go-ahead homers, cycles, three-homer games, golden sombreros, no-hitters,
  perfect games, immaculate innings, triple plays, CG shutouts, HR milestones (20, 30...), 7+ game streaks.

## Parking lot (post-MVP ideas, in the order they came up)
- ARCADE MODE: no-holds-barred chaos — every team gets a monster (a guaranteed homer a game to build around);
  ratings unlocked past 80, star-power spread ≫ 1, abilities common. A league setting, not the default.
- Flames flicker (a few frames); flame and icicle size grows with streak length.
- Customizable home screen (OOTP-style): windows are slots, the player picks what each one shows.
- Header font: a lightly re-drawn derivative of Jacquard 24 for readability (open-licensed; a modified version
  needs its own name).
- Revisit which information the home windows show.
- Postseason games and Year 2 (aging, the Gods' vote) — the first build stops at final standings.
- Player-made decisions (lineups, rotation order, bullpen roles) — today the AI manages every team, yours too.
- Cloud saves across devices (the password covers it for now).
- Uncapped bounce-back (an 85-start arm) as a rare, balanced "broken" combination; today's cap is
  `FATIGUE.minDaysBetweenStarts`.
- League adaptation: AI front offices chase the current meta over seasons, so dominant combos fade.
- Pitch types: repertoires, count/batter-aware selection, per-pitch velo/movement/command (log has room).
- Fielding instructions and alignments (infield in, double-play depth, guarding lines, shifts) so the
  "right play" is a choice, not just a probability; more situational plays.
- Mystical divisions and locations (keep MLB alignment), park factors by field direction, and extreme park
  features (e.g. a hazard in left field with a small chance of an instant homer). The spray model already
  knows the field for every batted ball, so this is a hook in `resolveBattedBall`.
- Traits / Gods' abilities (the `abilities` field exists; `bounceBack` already drives short-rest starts).
- Injuries; lineup rest days, platoons, pinch hitters, defensive subs.
- Over-rested buff/debuff (old design: after 2 days at 0 fatigue, ±8%, clutch-biased).
- Playoff games; divisional tiebreakers.

## Open questions
- Aces in four-man rotations reach 300+ strikeouts and 25 wins (41 starts, ~250 IP) — old-school by design;
  revisit if it feels too extreme.
- Cycles ~8/season (MLB ~2–5): doubles run a bit high (~30/600 vs 27.5) and regulars never rest.
- Strikeouts looking are 34% of Ks (MLB ~25%) — tune two-strike swings with the game loop.
- Baseline K% is 20%; real 2019 was 23%.
- Gods' decree mechanism: multiply ratings (×1.15 also widens the star gap) vs shift a dial.
- Positions/fielding fit at generation (a 30-glove shortstop is currently possible).
